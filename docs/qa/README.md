Снимки дополняют автоматические проверки и не заменяют приёмку физических устройств. Промежуточные локальные изображения остаются в игнорируемом output/; исходники, игровые ассеты и эти итоговые снимки сохраняются в Git.

Текущая автоматическая проверка пятой эры: 171 тест, включая прохождение четырёх боёв на seed 23 и 47 с заработанной прокачкой, миграцию профилей, отдельный кошелёк, контратаку берсерка и тайминг поддержки. Все 92 атласа пересобираются командой `npm run art:units`; отдельная проверка Medieval охватывает 320 кадров. Сборка, семь расчётных размеров интерфейса и минимум шрифта 16 px проходят. Браузерный снимок использует отдельный тестовый профиль; пользовательский прогресс для проверки не подменялся.
