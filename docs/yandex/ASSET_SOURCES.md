# Источники игровых и рекламных материалов

Подготовлено 04.10.2026. Перед отправкой владелец подтверждает право распространять исходные материалы. Этот перечень фиксирует доступное в репозитории происхождение, не устанавливает юридический статус чужого контента.

- Модели и анимационные атласы: исходники `src/art/*-rig.mjs`, `generate-*-sprites.mjs`, SVG-портреты и PNG-атласы `public/assets`. Для этой подготовки новые модели эпох не создавались.
- Арены и крепости: SVG в `public/assets`, генераторы в `src/art`. Реальные эмблемы стран и политические знаки в новых промоматериалах не использовались.
- Иллюстрации карт эпох: `public/assets/era-cards`, сохранённые задания в `src/art/era-card-prompts.json` и документах подготовки эпох. Сведения о правах и условиях инструмента, которым они созданы, подтверждает владелец. Исходная карточка девятой эпохи сохранена для обычной сборки; Яндекс использует `armored-arena.png`, составленную из существующих игровых SVG.
- Музыка: `src/art/generate-music.mjs`, `public/assets/audio/arena-theme.json` и звуковой файл в этой папке. Эффекты: WebAudio в `src/view/Sound.ts`. Внешние музыкальные сервисы и системный плеер не используются.
- Иконка и обложки: `scripts/create-yandex-promo.mjs`; оригинальные композиции из SVG-моделей проекта. Исходники SVG и PNG находятся в `docs/yandex/promo`. Это отдельные иллюстрации, не снимки интерфейса игры.
- Скриншоты и видео: сняты с локальной публичной сборки. Видео собрано из кадров реального браузерного боя с сохранением временных интервалов (`scripts/encode-yandex-video.mjs`). Без рекламы, посторонней игры, смонтированных побед и звуковой дорожки. Область игры занимает весь кадр.
- Шрифт промо: установленный системный Arial при преобразовании SVG в PNG; шрифт-файл в комплект не включён. UI использует системные шрифты браузера.
- Библиотеки выполнения: Phaser 3.90.0, Swiper 14.3.0, EventEmitter3 5.0.4. Полные тексты их лицензий из установленных пакетов включены в `public/third-party-notices.txt` и в ZIP; сборка обновляет файл автоматически. Номера версий сверять с `package-lock.json` при обновлении зависимостей.
- SDK Яндекса: загружается с `/sdk.js` на стороне площадки, копия SDK и ключи аккаунта в архив не добавлены.

После появления аккаунта подтвердить материалы и условия публикации, указать реальную почту поддержки и пройти договорный процесс кабинета. Не утверждать отсутствие каких-либо ограничений прав лишь на основании наличия файлов в Git.
