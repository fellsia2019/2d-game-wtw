# Комплект для карточки «Знамёна эпох»

Подготовлен 04.10.2026 для локального релизного кандидата 0.1.0. Порядок загрузки, настройки кабинета и приёмка настоящего SDK описаны в [отдельной инструкции после создания аккаунта](../../YANDEX_AFTER_ACCOUNT.md).

## Что загружать

- `promo/icon.png` — общая иконка 512×512.
- `promo/cover-ru.png`, `promo/cover-en.png` — обложки 800×470.
- `promo/showcase-ru.png`, `promo/showcase-en.png` — необязательные витринные обложки 1560×520.
- `promo/gameplay-ru.mp4`, `promo/gameplay-en.mp4` — горизонтальные видео 1280×720, H.264, около 22 секунд, без звуковой дорожки.
- `promo/screenshots/desktop-stone-ru.jpg`, `desktop-line-ru.jpg` — два десктопных снимка RU; файлы с окончанием `-en.jpg` — EN.
- `promo/screenshots/mobile-stone-ru.jpg`, `mobile-line-ru.jpg` — два мобильных снимка RU; файлы с окончанием `-en.jpg` — EN. Все восемь снимков JPEG 1280×720.
- [store-copy.json](./store-copy.json) — название, описания, инструкции, ключевые слова и комментарий модератору для копирования в поля формы.

Игровой ZIP находится отдельно: `artifacts/znamyona-epoh-yandex.zip` в корне проекта. В ZIP не нужно добавлять документы, промо или записи проверки. SVG в `promo` служат исходниками; в поля изображений загружать PNG.

## Как обновлять и проверять

```powershell
npm run promo:yandex
npm run check:yandex:promo
```

Первая команда создаёт иллюстрации из существующих игровых SVG. Вторая проверяет длину текстов, PNG-размеры, соотношение сторон и размеры JPEG, кодек, длительность и размер MP4. Для проверки видео требуется установленный `ffprobe` (из FFmpeg); это инструмент подготовки, в игру он не входит.

Видео и скриншоты снимаются отдельно после `npm run package:yandex`. Запуск `npm run preview:yandex:archive` обслуживает распакованный ZIP по вложенному адресу `/game/`. Для английского просмотра можно запустить в другом терминале `node scripts/preview-yandex.mjs --port 4180 --lang en`: только локальный сервер подставляет SDK mock языка; реклама не выдаёт награды, облако недоступно. В сам архив mock не включён.

Для повторной записи собирать JPEG-кадры браузерного screencast вместе с их исходными временными метками в `artifacts/yandex-video-ru/frames.json` или `artifacts/yandex-video-en/frames.json`, затем выполнить `node scripts/encode-yandex-video.mjs ru` / `en`. Скрипт сохраняет интервалы времени и кодирует MP4; исходные временные кадры находятся в игнорируемой папке `artifacts`.

## Происхождение и границы проверки

Иконка и обложки — отдельные композиции из моделей игры, не скриншоты. Игровые снимки и видео сняты с распакованной публичной сборки во встроенном браузере: первый бой Каменного века, два разных момента боя, обычный найм без Debug и подставленного прогресса. Для EN менялся только язык SDK через локальный mock. Мобильный интерфейс проверен в браузерной эмуляции 640×360; снимки получены браузером в 1280×720. Это не запись физического телефона.

`tests/browser/release.html` и снимки `docs/qa/yandex-release` служат проверке всех эпох с синтетическими состояниями. Их не использовать в карточке как доказательство прохождения. Промокомплект использует настоящую симуляцию релизной сборки.
