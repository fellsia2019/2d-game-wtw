# Арена наёмников

Одиночная браузерная игра на одной линии с прогрессией эпох. Игрок начинает в каменном веке; победа над Вождём Чёрного камня открывает бронзовый век с новым отрядом и Царём Медных ворот. В каждой эпохе поход состоит из четырёх боёв: игрок выбирает доктрину и четыре карты, контракт перед боем и усиления после первых трёх побед. Прежний поход с Комендантом сохранён как отдельная кампания для старых сохранений и повторов.

**Состояние на 27.09.2026:** каменная и бронзовая кампании реализованы. Автоматические проверки и production-сборка проходят; полная ручная приёмка на устройствах и публикация в Яндекс Играх ещё впереди. Полная лестница из 12 эпох описана в [плане прогрессии](./ERA_PROGRESSION_PLAN.html); [исходный дизайн-документ](./design-document.original.html) сохранён отдельно.

## Запуск и проверка

Нужен Node.js 20.19+. Для дополнительной числовой проверки звукового файла через `check-music.mjs` нужен установленный `ffmpeg` в `PATH`; сама игра и остальные проверки от него не зависят.

```powershell
npm ci
npm run dev
```

Vite покажет адрес игры, обычно `http://localhost:5173`.

```powershell
npm test
npm run build
node src/art/check-layout.mjs
node src/art/check-typography.mjs
node src/art/check-music.mjs
npm run preview
```

`npm test` запускает 50 тестов правил, эпох, талантов, сохранения, баланса, анимации и звука. Они проверяют обе четырёхбойные кампании, переход из камня в бронзу, рискованный контракт, миграцию старого сохранения, бонусы талантов, повтор боя после поражения и детерминированность симуляции. Сборка проверяет TypeScript и создаёт статический сайт в `dist/`.

Экран боя занимает всё окно. Панели здоровья и припасов расположены сверху, карты найма и обоз — снизу поверх арены. На портретном телефоне карты идут в два ряда; на низком альбомном экране — в одну компактную строку. Учитываются безопасные области экрана. `check-layout.mjs` проверяет расчёт свободного места для бойцов и крепостей на семи размерах. Для окончательной приёмки интерфейс нужно открыть на реальных устройствах и проверить поворот экрана.

Видимый текст игрового интерфейса начинается с 16 CSS-пикселей. Книга наёмников, экраны выбора и результаты имеют внутреннюю прокрутку на тесных экранах. `check-typography.mjs` проверяет декларации размеров шрифта в игровых CSS и галерее спрайтов; для окончательной проверки переносов и фактических стилей нужен браузер.

## Управление и прогресс

Выберите эпоху, доктрину и четыре карты. На первом экране главное действие — крупная кнопка «Играть» или «Продолжить игру», если поход уже сохранён. Дерево талантов, книга наёмников и рекорды показаны ниже отдельными карточками с описанием. Кнопка «Назад» сверху слева на внутренних экранах возвращает в главное меню и сохраняет незавершённый поход; из справочников она возвращает на предыдущий экран. На экране контракта сравните разведку, условие и награду. Во время боя нажимайте на карты или клавиши 1–4, когда накопятся припасы; бойцы действуют автоматически. Обоз повышает доход до двух раз за бой. Доступны пауза, включение звука и новая попытка. После боя выберите одно из трёх усилений. Звук выключен при запуске и включается только кнопкой.

Боевые эффекты синтезируются в браузере. Фоновая музыка — оригинальная 64-секундная тема «Марш Пепельного тракта» (120 BPM, ре минор): щипковые струны, низкая духовая мелодия, струнный фон и маршевая перкуссия. Файлы `public/assets/audio/arena-theme.ogg` и `.mp3` загружаются с адреса самой игры после включения звука; OGG имеет MP3-резерв. При паузе музыка сохраняет позицию, незавершённая загрузка не включает её поверх рекламы. Если оба формата недоступны, эффекты продолжают работать; включение звука повторяет попытку загрузки. Нажмите «Включить звук»: после успешного запуска прозвучат две короткие ноты. Браузеры разрешают запуск Web Audio после действия пользователя; если браузер отклонил запуск, кнопка остаётся в состоянии «Включить звук» для повторной попытки. Пауза, потеря фокуса и рекламная пауза останавливают эффекты и музыку.

В каждой новой эпохе есть восемь собственных бойцов: четыре стартовых, два за победы в ранних боях, один за рискованный контракт и один за босса для повторного похода. Открытия эпох и бойцов сохраняются после поражения. Знаки контракта продолжают открывать бойцов в прежнем походе. Книга и рекорды доступны из интерфейса. Сохранение записывается на экранах подготовки, контракта, награды и перед боем. При поражении сверху сразу доступна кнопка дерева талантов; после покупки можно повторить тот же бой, сохранив номер этапа, отряд, контракт и усиления похода. Выход в главное меню тоже сохраняет эту контрольную точку. При обновлении вкладки активный бой начинается заново с выбранным контрактом и тем же seed; предложения награды не меняются. Старый сейв версии 1/2 продолжается как прежний поход. Игра работает локально без SDK Яндекс Игр и сети. Потеря фокуса и показ внешней рекламы ставят симуляцию на паузу.

Симуляция выполняет шаг 1/30 секунды и не зависит от Phaser. Одинаковые seed и последовательность действий дают одинаковый результат. Phaser рисует состояние и воспроизводит эффекты.

## Сохранения и выпуск на Яндекс Играх

Текущее сохранение в `localStorage` предназначено только для разработки и тестирования. Подключение SDK Яндекс Игр сейчас не означает облачное сохранение: игра пока не вызывает `player.getData()` и `player.setData()`. Для нашего релиза публикация заблокирована до реализации загрузки, записи и проверки прогресса через облачное хранилище SDK Яндекс Игр.

Облачный профиль должен включать открытые эпохи и бойцов, таланты и очки, рекорды, текущий поход и его контрольную точку. Локальное сохранение остаётся резервом при отсутствии сети или SDK; при первом подключении нужен перенос локального прогресса и явное разрешение конфликта с облачной версией без удвоения очков талантов. Сохранять изменения следует после побед, покупки талантов, открытия эпохи и смены этапа; отказ записи и повторная синхронизация должны быть обработаны. Перед отправкой на модерацию проверить обновление страницы, смену устройства и аккаунта, отсутствие сети и возврат сети, а также авторизованного и неавторизованного игрока.

Ориентир для интеграции: [данные игрока в SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player) и [требования Яндекс Игр к сохранению прогресса](https://yandex.ru/dev/games/doc/ru/requirements/1/9).

По [требованиям к отображению](https://yandex.ru/dev/games/doc/ru/requirements/1/10) системная прокрутка страницы запрещена, но собственная прокрутка меню внутри игры допустима. Подготовка разделена на два последовательных игровых экрана: сперва один выбор из трёх тактик, затем состав отряда и кнопка начала похода. На маленьких экранах список бойцов прокручивается внутри окна игры. Кнопка звука во всех экранах показывает состояние иконкой: красная с перечёркнутым динамиком или зелёная со звуковыми волнами.

## Постоянное дерево талантов

Каждая победа даёт 1 очко талантов, победа над боссом — 2. Повторные походы тоже приносят очки; после поражения накопленные очки можно вложить в дерево талантов и сразу повторить сложный бой. Дерево открывается между боями, после поражения и в меню. Четыре ветки — урон, скорость атаки и лечения, здоровье бойцов и доход припасов. Каждый ранг даёт +5%, максимум пять рангов (+25%) в каждой ветке. Стоимость рангов одной ветки растёт от 1 до 5 очков. Бонусы действуют на союзников во всех эпохах и сохраняются отдельно от текущего похода; во время боя покупать таланты нельзя. При первом запуске новой версии прежние знаки контракта превращаются в стартовые очки талантов (не более 60), сами знаки остаются.

## Спрайты и анимации

После `npm run dev` откройте `/sprite-preview.html` на том же адресе: галерея показывает стойку, ходьбу и бой всех ролей с замедлением, паузой и покадровым просмотром. Её также можно открыть напрямую из [public/sprite-preview.html](./public/sprite-preview.html).

Исходники, устройство атласов и команды повторной генерации описаны в [src/art/README.md](./src/art/README.md). Каменный и бронзовый века добавляют 40 атласов по 16 кадров, отдельные арены и крепости. В игре используются готовые PNG. Тесты проверяют стабильность состояний и интерполяции при 60/144 Гц, остановку анимации на паузе и сброс между боями.

Правила и исходные гипотезы: [design-document.html](./design-document.html). Новая дорожная карта: [ERA_PROGRESSION_PLAN.html](./ERA_PROGRESSION_PLAN.html). Отклонения текущей версии: [DECISIONS.md](./DECISIONS.md).

## Что ещё требует проверки

- Полный ручной забег, поражение и быстрый повтор на ПК и телефоне, включая смену ориентации и фактическую читаемость при разных разрешениях.
- Прослушивание музыки и баланса эффектов на реальных динамиках, а также профилирование слабого Android-устройства.
- Отдельные реакции попадания и гибели, окончательная настройка боевого баланса и темпа забега после пользовательских тестов.
- Подключение реального показа рекламы только между боями, облачного сохранения и аналитики через SDK Яндекс Игр; затем проверка требований площадки и модерация.

## Музыкальная тема

`node src/art/generate-music.mjs` воспроизводит оригинальную композицию без чужих семплов (нужен FFmpeg в PATH). WAV создаётся во временном каталоге и удаляется после экспорта; в игре используются только сжатые файлы. `node src/art/check-music.mjs` проверяет длительность, отсутствие клиппинга и величину скачка сигнала на границе декодированной петли. Хвосты инструментов и реверберации замкнуты через границу такта. После декодирования края дополнительно сглаживаются на4 мс, чтобы сжатие не добавляло щелчок на стыке.

Пользовательский видеореференс использован только для анализа темпового пульса: автоматическая оценка дала кандидат около122 BPM; тема написана в120 BPM. Точное сходство тембров не подтверждено: аудиовход и живое прослушивание в агентской среде недоступны. Чужое аудио и кадры не входят в проект.
