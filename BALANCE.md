# Согласованный баланс двух эпох

Принят пользователем 28.09.2026. Менять базовые параметры только по новому указанию пользователя. Источник чисел — `src/data/content.ts`; применение усилений — `src/core/BattleSimulation.ts`. Локальные правки Debug не меняют эти значения.

Параметры каждого боя перечислены в порядке: доход врага / стартовые припасы / бонус HP / бонус урона. Бонусы применяются ко всем появляющимся врагам этого боя, включая босса и сопровождение. HP округляется до целого при появлении; урон в симуляции может быть дробным.

## Каменный век

1. **Ночная засада:** 5,8/сек / 0 / 0% / 0%. Ночной охотник и костяной щит.
2. **Костяной заслон:** 8/сек / 8 / 0% / 0%. Костяной щит и пращник племени.
3. **Тропа стаи:** 10/сек / 10 / +30% / +10%. Обычно вожак и два пращника; при приближении игрока к крепости ИИ выбирает вожаков. Ночной охотник есть в описании состава, но текущий план обычного найма третью позицию не использует.
4. **Вождь Чёрного камня:** 15/сек / 20 / +35% / +15%. Обычные подкрепления: щит → охотник → пращник. При 50% крепости выходит босс с щитом, охотником и пращником.

Босс: **810 HP, 23 урона, 25% брони**, атака раз в 1,3 секунды. Базовые данные 600 HP и 20 урона умножаются на усиления четвёртого боя.

## Бронзовый век

1. **Дорога колесниц:** 13/сек / 10 / +10% / +5%. Колесница → копейщик → лучник.
2. **Бронзовая фаланга:** 15/сек / 20 / +15% / +10%. Страж ворот → копейщик.
3. **Храмовые стены:** 16/сек / 20 / +20% / +15%. Обычно страж и два лучника; при приближении игрока к крепости ИИ выбирает стражей. Колесница есть в описании состава, но текущий план обычного найма третью позицию не использует.
4. **Царь Медных ворот:** 17/сек / 25 / +28% / +15%. Обычные подкрепления: страж → лучник → лучник. При 50% крепости выходит босс со стражем, лучником и колесницей.

Босс: **1000 HP, 30 урона, 45% брони**, атака раз в 1,3 секунды. Тяжёлый удар задевает до трёх дополнительных целей в радиусе 55 с половинным уроном. База в данных — 781 HP и `30 / 1.15` урона; итоговые 1000/30 получаются с усилениями четвёртого боя. Другие значения в Debug изменят и итоговые параметры босса. Сам босс не получает бонус брони фаланги.

## Общие правила

- Припасы и численность бойцов не имеют потолка. Враг проверяет закупку раз в 1,8–2,9 секунды и покупает по своему плану, пока хватает припасов; первая проверка через 2,5 секунды. Игрок покупает сразу без кулдауна.
- Базовый доход игрока — 6/сек в Каменном веке, 8/сек в Бронзовом. Ранги местного и глобального талантов дохода складываются и умножают текущий доход. Интерфейс показывает округлённое число: 8 с +5% фактически означает 8,4/сек.
- После 300 игровых секунд обе стороны получают ещё +2 припаса/сек. На 420-й секунде исход сравнивает доли здоровья крепостей; живой босс не позволяет засчитать победу игрока.
- Крепость врага — 100 HP. Первый порог 50% включает глиф на 5 игровых секунд; в финале сразу появляется босс. Пересекающий порог удар не уничтожает крепость. До гибели босса крепость остаётся защищённой даже после глифа.
- Общий бюджет входящего урона босса: при появлении 15% максимального HP, восстановление полного HP за 6 игровых секунд, накопление до 25%. Он ограничивает общий урон всех атак и защищает фазу босса от мгновенного уничтожения толпой.
- Бронзовое построение добавляет +12 процентных пунктов брони стражам и копейщикам обеих сторон рядом с союзным стражем/копейщиком в пределах 72; предел брони 75%. Копейщики получают полный бонус против любой ненулевой базовой брони. Это действующие правила, а не новые изменения баланса.

Текущие автоматические сценарии прохождения с прежней прокачкой требуют обновления. Принятие баланса пользователем не означает, что весь набор тестов проходит; статус — в [README.md](./README.md).
